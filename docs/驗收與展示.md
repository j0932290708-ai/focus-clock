## 人工驗收表

### 啟動與背景

- [ ] 連點兩次啟動檔，只出現一個程式與一個通知區圖示
- [ ] 關閉主視窗後，通知區圖示仍存在
- [ ] 通知區圖示右鍵可重新打開及結束程式
- [ ] 修改快捷鍵後可成功打開主畫面
- [ ] 快捷鍵被其他程式占用時顯示中文錯誤

### 排程

- [ ] 可新增、編輯、刪除、啟用及停用排程
- [ ] 開始時間改變後，當天執行狀態會重設
- [ ] 兩個已啟用排程重疊時不能儲存
- [ ] 停用排程不會阻止其他排程儲存

### 專注安全

- [ ] 安全測試可用 Esc、Shift+S、右鍵及長按退出
- [ ] 正式模式按 Shift+S、右鍵、Alt+F4、Ctrl+W、Escape、F11 不退出
- [ ] 正式模式長按五秒後會再次詢問是否緊急解鎖
- [ ] 倒數完成後由主程序自動解除
- [ ] Ctrl+Alt+Delete 仍能正常使用

### 專注網頁

- [ ] 正常網址可以載入
- [ ] 網頁載入失敗時仍顯示倒數與退出方式
- [ ] 攝影機、麥克風、通知與定位權限被拒絕
- [ ] 下載、新視窗、跨網域導航及跨網域 301／302 重新導向被阻止並顯示中文提示

### 健康提醒

- [ ] 超過 60 分鐘時，設定畫面先顯示過勞提醒
- [ ] 滿 60 分鐘時只顯示一次角落提醒，不遮住整個工作畫面
- [ ] 恰好 60 分鐘完成時，主畫面顯示休息建議

## 3～5 分鐘展示流程

1. **介紹目的（30 秒）**：說明這是 Windows 專注排程工具，不是作業系統安全鎖。
2. **建立排程（45 秒）**：設定名稱、時間、45 分鐘與學習網址，展示啟用開關。
3. **錯誤防護（35 秒）**：新增重疊排程，展示中文阻擋訊息。
4. **安全測試（45 秒）**：開啟專注頁面，展示倒數、Shift+S 或右鍵退出。
5. **正式模式設計（45 秒）**：說明主程序計時器、長按加確認與 Ctrl+Alt+Delete 保留。
6. **網站安全（35 秒）**：說明權限、下載、新視窗與跨網域導航預設被拒絕。
7. **桌面整合（30 秒）**：展示自訂快捷鍵、通知區右鍵與單一實例。
8. **總結（20 秒）**：強調不關閉其他程式、規模適中、可安全解除。

## 老師可能會問

**為什麼不用真正封鎖 Windows？**  
一般應用程式不應封鎖 Windows 安全畫面。本專題採取全螢幕置頂遮罩，兼顧自律與資料安全。

**為什麼由 main.js 管理結束時間？**  
因為主程序比畫面穩定；即使顯示倒數的畫面故障，時間到仍能解除。

**為什麼限制網站權限？**  
專注頁面只需要顯示內容，不需要攝影機、麥克風、定位或下載，因此採最小權限原則。
