# 專注番茄鐘 Focus Clock

這是一套適合升大學專題展示的跨裝置自律時鐘。Windows 可使用 Electron 桌面版，手機、平板與一般瀏覽器可使用 PWA 網頁版；使用者能設定每日開始時間、持續分鐘數與學習網址。

本專題刻意維持簡單，主要使用 HTML、CSS、JavaScript 與 Electron（把網頁介面包成桌面程式的工具），沒有加入資料庫、登入或複雜框架。

## 平台能力（請先閱讀）

| 能力 | Windows 桌面版 | Web／PWA／Android APK |
| --- | --- | --- |
| 排程啟動 | 程式保持執行時檢查，可留在通知區 | **前景版**：必須保持畫面開啟 |
| 背景、熄屏、關機 | 關機／休眠時不保證準時 | 不保證；APK 沒有原生背景鬧鐘或通知排程 |
| 限制其他程式 | 全螢幕置頂自律工具，不是系統鎖 | 不支援阻止切換其他 App |
| 提前退出 | 安全測試快捷退出；正式模式按住五秒再確認 | 「直接結束」再確認 |
| 網站 | HTTPS、同來源導航限制 | HTTPS iframe，無法保證網站允許嵌入或限制其同源導航 |
| 無網路 | 本地畫面可用；遠端網站需要網路 | PWA 須先在線完整快取；APK 有內建檔案；遠端網站需要網路 |

安裝成功、打包成功、手機尺寸瀏覽器測試，都不等於 Android 真機驗收。最新修正與尚未完成的驗收見 [2026-09-03 修正紀錄](docs/audit-fixes-2026-09-03.md)。

## 主要功能

- 新增、編輯、刪除、啟用或停用每日排程
- 自訂開始時間、持續分鐘數與專注網址
- 禁止儲存互相重疊的已啟用排程
- 無網址時顯示本地專注畫面
- Windows 主程序負責倒數結束與自動解除，專注畫面崩潰時提前解除
- Windows 正式模式使用全螢幕置頂限制一般切換
- Windows 安全測試模式可用 Esc、Shift+S 或右鍵快速退出
- Windows 正式模式可按住滑鼠、Enter 或空白鍵五秒並再次確認緊急解鎖
- Windows 拒絕專注網站的裝置權限、下載、新視窗、跨來源導航與重新導向
- Windows 可從四組安全選項中自訂開啟程式的快捷鍵
- Windows 單一實例保護，重複啟動只會打開既有視窗
- Windows 通知區圖示右鍵選單可打開或結束程式
- 連續專注滿一小時時顯示不阻塞工作的休息提醒
- 手機與平板可加入主畫面，排程會儲存在目前瀏覽器
- 網頁內可直接按「安裝 App」，安裝後會顯示番茄鐘桌面圖示
- 手機專注畫面提供「直接結束」按鈕，確認一次即可返回排程
- 排程可選擇錯過後 5 分鐘內補跑一次，或只在指定分鐘啟動
- 舊資料遷移、重複 ID 修復、損壞資料警告與備份復原
- 版本化 JSON 匯入／匯出；下載不支援時可複製備份文字

## 一般使用

正式展示可從 GitHub Release 或成功的 GitHub Actions 成品下載 `FocusClock-1.0.0-Windows.exe`，老師不需要安裝 Node.js。尚未發布時，可先依下方開發步驟執行打包後產生。

1. 點兩下執行檔。
2. 新增排程並選擇開始時間與分鐘數。
3. 可先按「安全測試」確認畫面與網址。
4. 主視窗關閉後，程式仍會留在 Windows 通知區等待排程。

## 開發執行

1. 安裝 Node.js。
2. 在 VS Code 開啟本資料夾。
3. 執行 `npm install`。
4. 執行 `npm start`。
5. 執行 `npm test` 檢查邏輯、離線路由、儲存故障、通訊來源與生命週期模擬。
6. 執行 `npm run dist:win` 可製作 Windows 可攜版。
7. 網頁回歸測試：先 `npx playwright install chromium`，再 `npm run test:e2e`。請使用獨立測試資料。
   包含桌面／手機尺寸的操作與 axe WCAG A／AA 基礎掃描，結果保存在 `playwright-report/`。自動掃描不能代替螢幕閱讀器與真機驗收。
8. Windows 原生介面回歸預設暫停：`npm run test:desktop` 不會開視窗。只在確認環境正常、同意短暫顯示正式專注視窗後執行 `npm run test:desktop -- --allow-window`。使用獨立測試資料、80 秒退出保護，第一次失敗便停止整批，不重試；不能在需要保持桌面可用的工作期間執行。本次本機受圖形程序啟動錯誤阻擋，尚未通過，CI 結果也不代替展示電腦或 Android 真機驗收。

## 手機與平板使用

1. 將專案發布到支援 HTTPS 的網站（例如 GitHub Pages）。
2. 用手機、平板或電腦開啟網址，按「安裝 App」；iPhone／iPad 依畫面提示從 Safari 加入主畫面。
3. 新增排程後保持網頁開啟；時間到會進入手機專注畫面。
4. 要提前離開時按右下角「直接結束」，再確認一次即可。

## Android APK

- GitHub Actions 的 `Android APK build` 會自動產生可安裝的 `FocusClock-1.0.0-Android.apk`。
- APK 安裝後會在 Android 主畫面顯示「專注番茄鐘」圖示，點擊即可開啟。
- 開發時執行 `npm run android:sync` 可同步網頁檔案，具備 Android SDK 的電腦可再執行 `npm run android:apk`。
- 此專題版使用測試簽章，適合直接分享與課堂展示，不用上架 Google Play。

## 排程限制

- 程式必須保持執行，排程才會啟動。
- 電腦休眠、完全關機或程式未執行時，不保證在指定時間啟動。
- 每個排程可設定「5 分鐘內補跑一次」或「只在指定分鐘啟動」。補跑仍倒數完整設定長度，可能影響緊接著的排程，請預留間隔。
- 排程以裝置當地時間判斷，跨午夜補跑記在原定日期；同一天不重跑。若改系統時鐘／時區，依變更後的當地時間與既有執行紀錄判斷，不應把它當跨時區旅行鬧鐘。
- 手機瀏覽器關閉或被系統暫停時，無法保證排程準時自動啟動。
- PWA 無法阻止使用者切換其他 App；iPhone／iPad 可另外使用「引導使用」，Android 可使用「螢幕固定」。
- 部分網站禁止嵌入其他頁面，專注網址在手機版可能無法顯示。
- 已啟用排程不能重疊，避免另一個排程在專注期間被靜默跳過。
- Windows 專注網站只能停留在原始網址的相同來源（協定、主機、連接埠）；需要跨網域登入的網站可能無法完整使用。Web iframe 不提供同等導航限制。
- 主要展示環境為 Windows 10／11 單螢幕。

## 安全說明

本程式不是 Windows 作業系統層級的安全鎖。它使用全螢幕置頂視窗限制一般操作，不會關閉或暫停其他程式，也不會封鎖 `Ctrl + Alt + Delete`。正式模式仍保留長按五秒加確認的緊急解鎖，避免程式故障時無法恢復操作。

專注網址只接受 HTTPS，不接受帳密型網址、公網或 localhost 的 HTTP。首頁測試伺服器使用 localhost HTTP 不代表遠端專注內容也有 HTTP 例外。Windows 遠端內容保留 sandbox、contextIsolation、webSecurity，不忽略憑證錯誤。

Windows 排程與設定先寫暫存檔並同步後再替換，保留 `.bak`；損壞原檔另存 `.corrupt-*`，若不能保留則停止覆寫。Web 保存上一版及損壞原文，警告不會自動消失。這些保護仍不能取代自行匯出備份；清除瀏覽器資料會刪掉本地排程。

## 程式架構

```text
main.js（主程序）
├─ 排程檢查、主計時器、視窗保護
├─ 快捷鍵、通知區圖示、單一實例
└─ WebView 權限與導航安全
   ├─ index.html + renderer.js（設定畫面）
   └─ focus.html + focus.js（專注畫面與倒數顯示）

logic.js（可測試的排程與網址純規則）
storage.js（依序寫入、原子替換、備份復原）
security.js（本地視窗／主 frame 身分與通訊大小限制）
preload.js / focus-preload.js（有限的安全通訊橋樑）
```

人工驗收表與 3～5 分鐘展示流程請參考 [`docs/驗收與展示.md`](docs/驗收與展示.md)。
