# 專注番茄鐘

這是一個適合升大學專題展示的 Windows 自律時鐘。程式刻意保持簡單，主要使用 HTML、CSS、JavaScript 與 Electron（把網頁介面變成桌面程式的工具）。

## 已完成的功能

- 自行設定每天的開始時間與持續分鐘數
- 使用滑動開關啟用或停用排程
- 可加入專注網址，時間到後固定顯示該網頁
- 未填網址時顯示全螢幕鎖定畫面
- 原本的程式不會被關閉，會留在背景
- 超過 60 分鐘時提醒休息
- 使用 Ctrl + Alt + P 快速打開主畫面
- Windows 右下角圖示提供右鍵選單
- 安全測試模式可以正常截圖或切換視窗
- 專注畫面可按 Shift + S、滑鼠右鍵或長按五秒退出

## 如何啟動

1. 下載或複製這個專案。
2. 電腦需先安裝 Node.js。
3. 直接點兩下「啟動番茄鐘.bat」。
4. 第一次開啟會自動安裝需要的檔案。

也可以在 VS Code 的終端機依序執行 npm install 與 npm start。

## 安全限制

一般 Windows 程式不能封鎖 Ctrl + Alt + Delete，也不應強制停止其他程式，否則可能造成未儲存的資料遺失。本專題使用全螢幕置頂畫面限制一般操作，同時保留安全退出方式。
